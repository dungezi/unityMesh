# Stylized Mesh Studio v1.0.1

Unity 网格减面、顶点塑形与 UV 编辑工具。本版本修复预览显示、撤销和场景导航问题，并优化表情预览的处理开销。

- 右键相机导航时 W/A/S/D 正常传递给 Unity；松开右键后使用 Q/W/E/R 切换顶点工具。
- 预览隐藏控制全部副本部件，刷新不会重新显示。
- 表情滑块不再每次更新都烘焙整块网格或重新读取三角形。
- 支持逐步撤销与重做，保留网格、UV 和表情的中间状态。
- 修复缩放蒙皮模型的手柄偏移及活动表情的重复变换。

安装：下载 `.unitypackage` 并导入 Unity，打开 **Tools → Stylized Mesh Studio → 网格改模工具**。也可解压 UPM ZIP，通过 Package Manager 的 **Add package from disk** 选择 `package.json`。两种方式择一。

验证：Unity 2022.3.22f1 的 21 项自动集成测试、7 项托管减面算法测试，以及安装包导入与原生导出检查通过。自动场景事件检查不代替人工操作检查；尚未用 Eku/Mafuyu 的真实模型测试。

默认保留原材质。可选色块 Shader 面向 Built-in / VRChat PC。编辑作用于预览副本，结果另存为独立网格和完整 Prefab。
