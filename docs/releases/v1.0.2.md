# Stylized Mesh Studio v1.0.2

修复有大量表情或密集 UV 边界的模型难以减面的问题。

- 新增 **常规预设** 和 **强减面预设**。常规预设不固定全部表情移动区域；强减面预设额外允许简化 UV 接缝、UV 折叠边界与开放边界。
- 表情名称与帧数据始终保留。允许简化表情区域后，形状会近似处理，需要检查眨眼、口型及关节变形。保守预设仍固定表情区域。
- 显示实际固定顶点数量；无变化时明确提示“未减面”，不会新增无效撤销状态。约束阻止达到目标时给出提示。
- 全部顶点已固定时跳过无效简化，提高有大量表情时的响应。

更新后选择当前部件，点击 **常规预设** 再减面。若幅度仍不足，使用 **强减面预设** 并调整保留率；该模式允许改变边界，需检查贴图拉伸与轮廓。

用户提供的模型只用于本地验证，不包含在仓库或 Release 附件中。验证范围与结果见附件报告。
